## ⚽ FIFA World Cup 2026 Dashboard – Power BI

## 📌 Project Overview

- This project is an interactive FIFA World Cup 2026 Dashboard developed using Microsoft Power BI. The dashboard provides a visual representation of FIFA World Cup data, including team rankings, match statistics, tournament stages, and country-wise analysis.

- The project is designed to present football tournament data through interactive charts and an attractive dark-themed dashboard.

## 🎯 Dashboard Features

1. Home Page – Team Overview

- Displays AFC team information.
- Shows FIFA rankings of Team 1 and Team 2.
- Uses a FIFA World Cup 2026-themed design.
- Provides navigation to the dashboard and results page.

2. World Cup Result Page

The results dashboard includes the following visualizations:

- Count of Group by City: Displays the distribution of groups across different cities.
- Count of Team 1 by Date: Shows the number of Team 1 records across different dates.
- Count of Stage: Represents the count of matches or records across tournament stages.
- Count of Team 1 by Country: Displays country-wise distribution of Team 1 records.

## 🛠️ Tools & Technologies Used

- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization
- Data Cleaning and Transformation
