# FIFA-WORLDCUP-DASHBOARD-
This project is an interactive FIFA World Cup 2026 Dashboard created using Microsoft Power BI. It provides a visual comparison of two football teams by displaying their FIFA rankings and performance through interactive charts and KPIs. The dashboard is designed with a modern dark theme inspired by the FIFA World Cup 2026 branding.
